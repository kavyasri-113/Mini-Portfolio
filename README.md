# 🌐 Personal Portfolio Website

A modern and responsive personal portfolio website developed using **HTML, CSS, and JavaScript** to showcase my technical skills, projects, and professional journey.

## 🚀 Live Demo

🔗 https://kavyasri-113.github.io/Mini-Portfolio/

## 📌 Features

- Responsive and clean user interface
- Home, About, Skills, Projects, and Contact sections
- Downloadable resume
- Smooth scrolling navigation
- GitHub and LinkedIn profile links
- Project showcase
- Professional portfolio design

- JavaScript
- GitHub
